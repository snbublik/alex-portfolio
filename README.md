# Портфолио Александры

Статический сайт на HTML, CSS и JavaScript.

## Файлы
- `index.html` — разметка главной страницы.
- `styles.css` — стили и адаптивная верстка.
- `script.js` — мобильное меню и год в футере.
- `assets/images/portrait.png` — портрет для сайта.

## Запуск
Откройте `index.html` в браузере.

## Перед публикацией
В `index.html` замените `hello@example.com`, ссылку Telegram и `href="#"` для резюме на актуальные контакты. Проверьте, какие материалы можно публиковать открыто.
